# Student Management System

A full-stack Student Management System developed using ASP.NET Core Web API and Angular.

## Features

- Add Student
- View Student List
- Edit Student Details
- Delete Student
- Form Validation
- Routing
- REST API Integration
- CRUD Operations

## Technologies Used

### Frontend
- Angular
- TypeScript
- HTML
- CSS
- Angular Signals
- Reactive Forms

### Backend
- ASP.NET Core Web API
- C#
- Entity Framework Core

### Database
- SQL Server

## Project Structure

Student-Management-System
├── Frontend (Angular)
└── Backend (ASP.NET Core Web API)

## API Methods

- GET
- POST
- PUT
- DELETE
